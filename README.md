# 교하성당 클래식기타반 · 나의 연습실

GitHub Pages에서 동작하는 클래식기타 연습·레퍼토리 관리 PWA입니다.

## 주요 화면

- **오늘**: 15·30·45분 연습 선택, 3단계 루틴, 연속 연습일과 월간 시간 기록
- **레퍼토리**: 곡별 숙련 단계, 현재/목표 BPM, 다음 연습 메모 관리
- **월례회**: 매월 마지막 토요일을 기본 발표일로 제안하고 선곡·녹음·리허설 준비도 관리
- **강좌**: 기존 초급~고급 강좌, 영상, 악보, Q&A 및 관리자 기능 유지

## 파일 구조

- `index.html`: 기존 강좌·관리·Firebase 화면과 데이터
- `practice-app.js`: 오늘 연습, 레퍼토리, 월례발표회 상태와 화면
- `practice-app.css`: 모바일 우선 내비게이션과 반응형 디자인
- `curriculum.json`: GitHub에서 동기화되는 공용 강좌 데이터
- `functions/`: 관리자 저장을 처리하는 Firebase Functions

개인 연습 기록은 브라우저의 로컬 저장소에 보관되며 공용 GitHub 강좌 데이터와 분리됩니다.
