권장 운영 방식
수강생이 변경사항을 보게 하려면 공개 Gist를 사용하고, 관리자만 토큰으로 수정하세요.

토큰은 브라우저 로컬 저장소에만 보관되며, GitHub Pages 정적 호스팅에는 서버가 없으므로 공개 HTML에 토큰을 직접 넣지 않는 것이 안전합니다.

기초를 제대로 마스터하는 단계별 커리큘럼

제공하신 두 개의 유튜브 플레이리스트를 기반으로 초급 I → 초급 II 순서로 학습 흐름을 재구성했습니다. 강좌별 유튜브 링크, 악보 구글드라이브 링크, 강의 목표를 한 화면에서 관리할 수 있습니다.

초급 완성 로드맵

초급 I에서는 자세·튜닝·오른손과 왼손의 기본기를 안정화하고, 리듬과 간단한 선율 읽기·아르페지오를 익힙니다. 초급 II에서는 포지션 이동, 바레, 슬러, 표현력, 합주·독주 준비까지 확장하여 기초 과정을 마스터하도록 설계했습니다.
